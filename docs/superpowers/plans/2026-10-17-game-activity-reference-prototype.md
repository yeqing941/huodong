# 游戏活动参考库原型 V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成一个无需后端、可直接浏览和体验核心流程的游戏活动参考库 Web 原型 V0.1。

**Architecture:** 采用单个静态 HTML 文件承载页面结构、样式和原型交互，通过前端状态切换模拟 11 个 MVP 页面。使用内置模拟数据，不接入真实认证、爬虫、AI、数据库或持久化存储；页面间通过侧边导航、卡片点击、弹窗和抽屉完成跳转与反馈。

**Tech Stack:** 原生 HTML、CSS、JavaScript；浏览器原生运行；使用本地静态预览服务验证。

---

### Task 1: 建立原型壳层与模拟数据

**Files:**
- Create: `e:/huodong/prototype/index.html`

- [ ] **Step 1: 创建单文件原型入口**

实现以下固定结构：

- `state.page`、`state.role`、`state.selectedActivity`、`state.filters` 等原型状态。

- [ ] **Step 2: 实现通用视觉样式**

采用已确认的专业后台工作台方向：

- 页面背景使用浅灰蓝色；
- 侧边栏使用深蓝灰色；
- 主操作使用蓝色；
- 卡片、表格、标签、状态徽章使用统一圆角和边框；
- 活动截图使用 CSS 渐变模拟，不依赖外部图片；

- [ ] **Step 3: 加入静态检查入口**

确保 HTML 可直接通过浏览器打开，并在页面底部或设置区域显示“原型演示 · V0.1”，不引入构建工具和外部依赖。

### Task 2: 实现浏览与收藏核心路径

**Files:**
- Modify: `e:/huodong/prototype/index.html`

- [ ] **Step 1: 实现活动库页面**

活动库页面展示：

- 活动形式筛选；
- 游戏类型筛选；
- 游戏名称/活动名称搜索；
- 清空筛选；
- 新增活动入口；
- 活动卡片网格；
- 当前结果数量。

筛选输入和下拉选择实时更新卡片列表；无结果时显示清空筛选操作。

- [ ] **Step 2: 实现活动详情页**

点击卡片进入详情页，展示：

- 活动大图与缩略图切换；
- 活动名称、游戏、游戏类型、活动形式标签；
- 来源 URL；
- 采集方式、入库时间；
- 收藏按钮；
- 相关活动卡片。

- [ ] **Step 3: 实现收藏状态和我的收藏**

支持从卡片和详情页收藏/取消收藏。我的收藏页只展示当前模拟用户的收藏数据，空状态提供返回活动库按钮。

- [ ] **Step 4: 完成浏览冒烟路径**

浏览器中验证：活动库 → 搜索/筛选 → 点击活动卡片 → 收藏 → 我的收藏 → 返回详情。

### Task 3: 实现运营采集工作台路径

**Files:**
- Modify: `e:/huodong/prototype/index.html`

- [ ] **Step 1: 实现活动录入页/抽屉**

展示活动名称、游戏名称、游戏类型、活动时间、来源 URL、标签选择和截图区域。保存时使用预设结果：显示成功 toast，并将示例活动加入活动库；复杂图片上传仅模拟状态反馈。

- [ ] **Step 2: 实现爬虫任务中心**

展示任务列表、状态、来源、时间、新增/重复/失败/待打标数量。支持：

- 手动触发已配置爬虫弹窗；
- 触发后将任务状态切换为“执行中”，随后展示预设“部分完成”结果；
- 查看任务详情抽屉；
- 失败记录重试 toast；
- 进入 AI 待审核队列。

- [ ] **Step 3: 实现 AI 待审核队列**

运营角色可查看 AI 候选标签、置信度和截图，并执行接受建议、补充标签、提交管理员确认。提交后状态变为“待管理员确认”。

超级管理员角色可执行最终确认/修正，确认后记录变为正式活动。

- [ ] **Step 4: 完成运营冒烟路径**

浏览器中验证：切换运营角色 → 爬虫任务 → 手动触发 → 查看任务结果 → AI 待审核 → 接受建议/提交确认。

### Task 4: 实现管理员页面和角色入口

**Files:**
- Modify: `e:/huodong/prototype/index.html`
