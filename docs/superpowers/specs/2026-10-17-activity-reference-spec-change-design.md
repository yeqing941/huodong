# 游戏活动参考库规格调整设计

## 目标

在不扩大 MVP 产品边界的前提下，补齐已确认的活动编辑、批量录入、爬虫采集、活动归档、三级标签和游戏类型管控能力，并据此修改 PRD 与 Web 原型。

## 范围边界

本次仅调整既有页面和既有业务域，不新增独立业务模块，不接入真实后端、数据库、外部爬虫站点或真实文件解析器。

原型继续使用模拟数据和预设结果，重点验证页面入口、角色权限、交互顺序和结果反馈。

## 规格变更

### 1. 活动编辑

保留“活动详情 → 编辑活动”路径，不新增编辑页面。

编辑表单需要回填并允许修改：

- 活动名称；
- 游戏名称；
- 游戏类型；
- 活动时间；
- 来源 URL；
- 活动描述；
- 已有活动形式标签。

标签编辑支持取消已有标签，并从已配置标签树中补充标签。保存后返回活动详情并显示保存结果。

权限：

- 运营可编辑自己录入的活动；
- 超级管理员可编辑全部活动；
- 普通用户无编辑入口。

### 2. 批量录入

在现有“活动录入”页面增加“单条录入 / 批量录入”页签，不新增页面。

批量录入原型流程：

1. 选择批量录入页签；
2. 选择预设 CSV/Excel 文件；
3. 展示导入预览表；
4. 标记有效记录和问题记录；
5. 导入有效记录或取消导入；
6. 显示导入结果统计。

问题类型仅覆盖 MVP 必要校验：

- 活动名称或游戏名称缺失；
- 标签不存在；
- 游戏类型已停用或不存在。

不实现真实文件解析，不增加批量编辑、批量删除或批量导出。

### 3. 爬虫任务

补齐现有“爬虫任务”页面的可体验采集流程，但仍使用预设结果模拟外部采集。

运营可以：

- 手动触发超级管理员已配置的来源；
- 查看任务创建、执行中和完成状态；
- 查看抓取进度；
- 查看新增、重复、失败和待打标数量；
- 查看失败 URL 和失败原因；
- 重试单条失败记录；
- 将采集结果进入 AI 待审核队列。

运营不能：

- 新增、修改、删除来源；
- 修改爬虫规则；
- 修改调度频率。

### 4. 活动归档与恢复

活动删除采用软删除/归档，不做物理删除。

仅超级管理员可在活动详情页或活动库相关操作中执行“归档活动”：

- 二次确认并填写或选择归档原因；
- 归档后从正常活动库和筛选结果隐藏；
- 记录操作日志；
- 超级管理员可查看已归档活动并恢复。

运营和普通用户不显示归档入口。产品文案统一使用“归档”，避免与不可恢复删除混淆。

### 5. 三级标签树

标签树最多支持三级：一级、二级、三级。

仅超级管理员可管理标签：

- 一级标签：新增、编辑、排序，不允许删除；
- 二级标签：在一级标签下新增、编辑、排序、合并；
- 三级标签：在二级标签下新增、编辑、排序、合并；
- 新增一级标签不需要父级；新增二级、三级标签必须选择父级；
- 删除或合并前检查关联活动；
- 有关联活动时需先迁移关联活动，原型中以确认提示模拟；
- AI hints 与标签一起编辑。

### 6. 游戏类型配置

在现有“标签树管理”页面增加“活动形式标签 / 游戏类型”页签，不新增独立页面。

仅超级管理员可管理游戏类型：

- 新增游戏类型；
- 编辑名称和说明；
- 调整排序；
- 停用类型；
- 查看关联活动数量；
- 已被活动使用的类型不可直接删除，只能停用或迁移；
- 停用类型不能用于新的单条录入和批量录入；
- 历史活动保留原游戏类型；
- 活动库筛选只展示启用中的游戏类型。

## 页面调整

| 页面 | 调整内容 |
|---|---|
| 活动库 | 管理员增加归档/恢复相关入口或状态筛选；普通用户和运营不显示管理员操作 |
| 活动详情 | 增加编辑入口的完整回填；超级管理员增加归档入口；归档活动展示状态 |
| 活动录入 | 增加单条录入/批量录入页签；单条录入支持编辑回填；游戏类型读取配置 |
| 爬虫任务 | 增加进度、失败 URL、失败原因、单条重试和采集结果进入待审核 |
| AI 待审核 | 接收爬虫新增结果；保留运营初审和管理员最终确认流程 |
| 标签树管理 | 支持新增一级、二级、三级标签；增加游戏类型页签 |
| 爬虫配置 | 保持管理员维护来源、规则、频率；运营只能使用配置结果 |
| 操作日志 | 增加活动归档、恢复、批量录入、标签和游戏类型管理记录 |

## 原型交互验证目标

### 路径一：活动编辑

活动库 → 活动详情 → 编辑活动 → 修改游戏类型和标签 → 保存 → 返回详情并看到更新结果。

### 路径二：批量录入

活动录入 → 批量录入 → 选择预设文件 → 查看预览与问题记录 → 导入有效记录 → 活动库看到新增记录。

### 路径三：采集与审核

运营角色 → 爬虫任务 → 触发采集 → 查看执行进度和结果 → 查看失败 URL → 重试 → AI 待审核 → 提交管理员确认 → 超级管理员最终确认。

### 路径四：管理员配置和归档

超级管理员 → 标签树管理 → 新增指定层级标签或管理游戏类型 → 活动详情 → 归档错误活动 → 查看日志。

## 明确不做

- 不接入真实爬虫站点；
- 不实现真实文件解析器；
- 不实现真实认证、后端权限和数据持久化；
- 不增加独立批量录入页面；
- 不增加批量编辑、批量删除、批量导出；
- 不增加超出 PRD 的统计分析和通知系统。
