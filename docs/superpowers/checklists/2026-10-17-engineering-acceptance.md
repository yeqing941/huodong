# 工程验收清单

## 普通用户主线

- [ ] 登录成功并恢复当前会话
- [ ] 按标签、游戏类型、游戏名称组合筛选活动
- [ ] 查看活动卡片、详情和多张截图
- [ ] 收藏活动并在“我的收藏”中查看
- [ ] 取消收藏后列表和详情状态同步
- [ ] 普通用户访问运营和管理员接口返回 403

## 运营主线

- [ ] 登录后可新增和编辑自己录入的活动
- [ ] 上传至少一张截图并选择至少一个标签
- [ ] 手动触发已配置爬虫
- [ ] 查看任务状态、统计和失败记录
- [ ] 重试失败任务或单条失败记录
- [ ] 处理 AI 待打标记录并提交管理员确认
- [ ] 运营不能修改爬虫配置、标签树、用户或管理员审核结果

## 管理员主线

- [ ] 最终审核、修正标签并使活动进入 active
- [ ] 管理三级标签树和游戏类型
- [ ] 配置、启停爬虫来源和调度规则
- [ ] 归档和恢复活动，并要求归档原因
- [ ] 管理用户角色和停用状态
- [ ] 查询关键操作审计日志

## 工程与安全

- [ ] OpenAPI YAML 可解析且 `$ref` 可解析
- [ ] Django `check`、迁移和测试通过
- [ ] 前端类型检查和构建通过
- [ ] MariaDB 迁移与重启后数据保存验证通过
- [ ] 统一错误响应包含 code、message 和 request_id
- [ ] 未认证、越权、不存在、状态冲突和限流响应分别为 401/403/404/409/429
- [ ] 不提供批量导出、批量下载和全库 dump 路由
- [ ] 活动和配置使用软删除或归档，不物理删除历史记录
